# Ralph Progress Log
Started: Mon Feb 24 2026

## Codebase Patterns
- `.refreshable` cancels its task on view re-render — always use `Task.detached` + `withCheckedContinuation` pattern
- SyncService is available via `@Environment(SyncService.self)` in player views
- TrackView groups bets into Ticket structs by ticketId — work with tickets not raw bets for display
- Bet.gradeResult is `GradeResult?` enum (.win/.loss/.push), not a String — use enum comparison
- LiabilityService.calculatePayout(stake:odds:) returns profit only (not stake + profit)
