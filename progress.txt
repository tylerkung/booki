## Codebase Patterns
- SwiftData models use `@Model` decorator with `@Attribute(.unique)` for id field
- All models should be registered in BookiApp.swift schema array
- New Swift files must be added to project.pbxproj (PBXFileReference, PBXBuildFile, group children, and Sources build phase)
- Xcode project file IDs follow pattern `8A123455XXXX` for file refs and `8A123456XXXX` for build files
- Use `swiftc -parse` for syntax validation but expect SwiftData macro errors (normal)
