## Codebase Patterns
- SwiftData @Query with sort creates ascending order by default - no need for explicit order parameter
- Event filtering uses computed properties (like `availableEvents`) since SwiftData predicates have limitations with complex OR conditions
- Use `Calendar.current.date(byAdding:value:to:)` for date math in Swift
- Xcode IDE required for full typecheck - swiftc can't resolve SwiftData macros
- UUID case sensitivity: iOS UUID.uuidString returns UPPERCASE, PostgreSQL stores lowercase - always use `.lowercased()` when comparing UUIDs across systems
- Font registration: Space Grotesk fonts are in `Booki/Fonts/`, registered in Info.plist UIAppFonts. Use `Font.custom("SpaceGrotesk-Regular", size:)` etc.
- Theme typography: Use `Theme.font(size:weight:)`, convenience properties (`Theme.largeTitle`, `Theme.title1`, `Theme.title2`, `Theme.title3`, `Theme.headline`, `Theme.body`, `Theme.callout`, `Theme.subheadline`, `Theme.footnote`, `Theme.caption`, `Theme.caption2`), and `Theme.monoDigits(size:weight:)` for odds/numbers
- Only 2 system fonts remain: `.system(.title, design: .monospaced)` in PlayerClaimView and `.system(.title2, design: .monospaced)` in PlayersListView - these need actual monospace, not Space Grotesk
