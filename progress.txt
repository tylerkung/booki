## Codebase Patterns
- SQL migrations go in supabase/migrations/ with format NNN_description.sql
- Use `IF NOT EXISTS` for all CREATE TABLE and CREATE INDEX statements
- RLS policies follow naming pattern: `tablename_action_description`
- Document all migrations in SUPABASE_MIGRATIONS.md under "Completed Migrations"
- auth.uid() is used for RLS policies to reference current authenticated user
