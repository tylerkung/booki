## Codebase Patterns
- GameCardView.swift contains button components (SpreadButton, MLButton, TotalButton, OddsButton) that follow a consistent pattern with isPressed/showSelectionHighlight states, gradient backgrounds, and spring animations
- Theme.swift provides consistent styling - use Theme.cardGradient, Theme.accent, Theme.textPrimary, etc.
- Market types are accessed via event.markets?.first { $0.type == .spread/.moneyline/.total }
- Xcode command line build is not available (xcodebuild requires full Xcode, not just Command Line Tools)
- For SwiftUI Buttons with transparent backgrounds, use .contentShape(Rectangle()) to expand tap area
