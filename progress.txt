## Codebase Patterns
- Use Theme.swift for all colors and styling - never use default iOS colors
- Access Supabase client via `SupabaseClientManager.shared.client`
- Supabase credentials are stored in Info.plist (SUPABASE_URL, SUPABASE_ANON_KEY)
- Config files go in Booki/Config/, Services go in Booki/Services/
- Auth views go in Booki/Views/Auth/ directory
- Use AuthTextFieldStyle and PrimaryButtonStyle for auth forms (defined in SignUpView.swift)
