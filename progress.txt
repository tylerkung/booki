## Codebase Patterns
- Dashboard SPA uses Alpine.js with hash-based routing in `landing/dashboard/dashboard.js`
- Routes parsed via `parseRoute()` on `hashchange` events — use regex for parameterized routes
- State variables (e.g. `selectedPlayerId`) live in the Alpine data object returned by `dashboardApp()`
- Edge functions called via `callEdgeFunction(name, body)` helper with auth headers
- Player data cached in `playerMap` (keyed by id) for O(1) lookups
