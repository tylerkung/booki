## Codebase Patterns
- SwiftData @Query with sort creates ascending order by default - no need for explicit order parameter
- Event filtering uses computed properties (like `availableEvents`) since SwiftData predicates have limitations with complex OR conditions
- Use `Calendar.current.date(byAdding:value:to:)` for date math in Swift
- Xcode IDE required for full typecheck - swiftc can't resolve SwiftData macros
- UUID case sensitivity: iOS UUID.uuidString returns UPPERCASE, PostgreSQL stores lowercase - always use `.lowercased()` when comparing UUIDs across systems
