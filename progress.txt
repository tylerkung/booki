## Codebase Patterns
- LiabilityService.calculatePayout(stake:odds:) returns profit only (not including stake)
- American odds formatting: positive gets '+' prefix, negative is as-is
- Theme.font() = Space Grotesk (titles), Theme.bodyFont() = IBM Plex Sans (body text)
- Status colors: Theme.accent (won/open), Theme.danger (lost), Theme.warning (pending), Theme.textMuted (void)
- Event display format: "league · awayTeam @ homeTeam"
- americanToDecimal/decimalToAmerican helpers exist inline in BetsListView/TicketDetailView — now centralized in PickPresenter
- Bet.eventDescription and Bet.sportLeague provide offline fallbacks when Event is nil
- Always use StatusPill + PickPresenter.mapStatus for pick status display — never use bet.status.rawValue inline
