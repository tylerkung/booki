## Codebase Patterns
- SQL migrations use numbered prefix format: `NNN_description.sql` (e.g., `007_auto_refresh_timestamps.sql`)
- Migration files include header comments with description and formatted sections
- All timestamptz columns are nullable by default, added with `ADD COLUMN IF NOT EXISTS`
- Document all migrations in SUPABASE_MIGRATIONS.md in the "Completed Migrations" section
- Edge Functions are in `supabase/functions/` with shared helpers in `_shared/`
- Sport/League -> API key mapping: `OddsAPIMapper.sportKeyMapping` (Swift) and `sportLeagueToApiKey` (TypeScript) must stay in sync
- For audit events on system actions, get `auth_user_id` from bookie via join: `bookies!inner(auth_user_id)`
- For system/cron operations, use 'system' as user_id for idempotency storage (not tied to specific user)
