## Codebase Patterns
- Web dashboard uses Alpine.js (`x-data`, `x-show`, `x-cloak`, `x-for`, `x-text`, `@click`) with Supabase JS client
- Routes are hash-based (`#/events`, `#/members/{id}`) parsed in `parseRoute()` — add new routes to the `routes` array
- Sidebar nav links in `app.html` between `<ul class="sidebar-nav">` tags
- Views are `x-show="route === 'xxx'"` sections inside `<main class="main-content">`
- Use existing CSS classes: `.card`, `.card-header`, `.card-title`, `.chip`, `.chip.active`, `.badge`, `.badge-muted/warning/success/danger`, `.data-table`, `.search-input`, `.filter-bar`, `.empty-state`, `.shimmer`
- Events are shared (bookie_id IS NULL) — use `.is('bookie_id', null)` in Supabase queries
- Sport DB values: `americanfootball_nfl`, `basketball_nba`, etc. — use `formatSportName()` for display
- State variables go at the top of `dashboardApp()`, methods below `init()`
- Computed getters use `get` syntax for Alpine reactivity
