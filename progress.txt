## Codebase Patterns
- Landing pages live in `landing/` directory — static HTML with shared `styles.css`
- OG/Twitter tag pattern: copy from index.html, update title/description/url per page
- Use `https://bookisports.com/assets/og-image.png` as og:image across all pages
- Canonical URLs use `.html` extension (static HTML on Netlify, no URL rewriting for pages)
- Nav bar pattern: copy from features.html for non-index pages (uses `index.html#pricing`, `index.html#waitlist`)
- Footer pattern is consistent across all pages: logo, copyright, Privacy/Terms/Twitter links
- Netlify config in `landing/netlify.toml` — only `/invite/*` has a redirect rule
- SEO landing page CSS classes: `.seo-section`, `.seo-pain-grid`/`.seo-pain-card`, `.seo-solutions-grid`/`.seo-solution-item`, `.seo-comparison-table` — all reusable across SEO pages
- Pain cards use `--accent-tertiary` (red icons), solutions use `.feature-number` (teal)
- Blog pages in `landing/blog/` use `../` prefix for root paths (../styles.css, ../assets/, ../features.html)
- Blog CSS classes: `.blog-hero`, `.blog-grid`, `.blog-card`, `.blog-article`, `.blog-prose`, `.blog-related`
- invite.html is standalone (no nav bar) — skip when updating nav across all pages
