## Codebase Patterns
- Supabase migrations use sequential numbering: `028_push_notification_tables.sql` is the next available
- Always use `IF NOT EXISTS` for tables and indexes in migrations
- RLS policies follow pattern: "Users can {verb} own {table}" with `auth.uid() = user_id`
- No local Supabase for lint — migration SQL validated manually
- No local Deno — typecheck validated by following existing _shared/ patterns
- Shared helpers use `createServiceClient()` for service-role DB access
- `sendNotification()` is fire-and-forget — import from `'../_shared/notifications.ts'`
- App uses `UIApplicationDelegateAdaptor` in BookiApp.swift for APNs token callbacks
- APNs JWT uses WebCrypto ECDSA P-256 (importKey pkcs8), cached 50 min
- Deep link routing: set `NotificationService.shared.pendingDeepLink`, observe with `.onChange` in target view, consume after navigation
- Use Codable structs (not AnyJSON dicts) for Supabase insert/upsert in iOS services
- iOS notification delegate needs `@preconcurrency UNUserNotificationCenterDelegate` for Swift 6
- Entitlements already have `aps-environment`, Info.plist has `remote-notification` background mode
