## Codebase Patterns
- SQL migrations go in supabase/migrations/ with format NNN_description.sql
- Edge Functions go in supabase/functions/<function-name>/index.ts
- Shared Edge Function utilities in supabase/functions/_shared/
- SwiftData models use @Attribute(.unique) for UUID primary keys
- iOS services use SupabaseClientManager.shared.client singleton
- Theme colors: Theme.accent, Theme.textPrimary, Theme.textSecondary, Theme.textMuted, Theme.cardBackground, Theme.background
- Dark theme Lists: use .scrollContentBackground(.hidden) and .background(Theme.background)
- List row styling: .listRowBackground(Theme.cardBackground)
- Bet slip is in BetSlipSheet.swift
- Player view tabs are in PlayerMainView.swift
- Game detail markets are in EventDetailView.swift
- Bookie players list is in PlayersListView.swift
