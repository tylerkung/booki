  - SwiftUI computed properties don't re-evaluate unless a state variable they reference changes
  - Use `lastRefreshTime` pattern: timer updates state -> triggers view re-evaluation -> computed properties use new time
  - Wrap state changes in `withAnimation()` to avoid jarring UI transitions
  - Timer naturally only runs when view is visible (SwiftUI lifecycle)
