## Codebase Patterns
- Player upsert logic exists in BOTH SyncService AND RealtimeService — update both when adding new Player fields
- PlayerRecord (download DTO) and PlayerUpsert (upload DTO) are both in SyncModels.swift — update both
- Supabase migrations go in supabase/migrations/ with sequential numbering (024 is next)
- PostgreSQL BEFORE UPDATE triggers run alphabetically — `trg_*` runs after `update_*` so `updated_at` is already modified
- Column-level RLS isn't supported in PostgreSQL — use a BEFORE UPDATE trigger to restrict which columns non-bookies can change
- CollectionStatus.displayName is a computed property on an enum — Player.displayName is a separate stored property, no conflict
