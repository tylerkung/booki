## Codebase Patterns
- LiabilityService.calculatePayout(stake:odds:) returns profit only (not including stake)
- American odds formatting: positive gets '+' prefix, negative is as-is
- Theme.font() = Space Grotesk (titles), Theme.bodyFont() = IBM Plex Sans (body text)
- Status colors: Theme.accent (won/open), Theme.danger (lost), Theme.warning (pending), Theme.textMuted (void)
- Event display format: "league · awayTeam @ homeTeam"
- americanToDecimal/decimalToAmerican helpers centralized in PickPresenter
- Bet.eventDescription and Bet.sportLeague provide offline fallbacks when Event is nil
- Always use StatusPill + PickPresenter.mapStatus for pick status display
- UUID case sensitivity: iOS uppercase, PostgreSQL lowercase — always .lowercased() for comparison
- Xcode IDE required for full builds — command-line swiftc can't resolve SwiftData macros
- Complex @ViewBuilder bodies cause type-checker timeouts — extract sub-views proactively
- Supabase migrations numbered sequentially: 001_, 002_, etc. in supabase/migrations/
- Edge functions deployed with: npx supabase functions deploy <name> --no-verify-jwt --project-ref vstfauqufwpdytmvjyfz
- Edge functions validate JWT in code (getUserIdFromAuthHeader), not at gateway level
- Shared helpers in supabase/functions/_shared/: cors.ts, supabase.ts, idempotency.ts, audit.ts, grading.ts
- Settlement payout math (American odds): win positive = -(stake * odds/100), win negative = -(stake * 100/abs(odds)), loss = +stake, push/void = 0
- Internal balance convention: positive = player owes bookie, negative = bookie owes player
- Append-only ledger: corrections via reversal entries (negated amount, type='reversal'), never UPDATE/DELETE
- auto_refresh_games has TWO grading paths: main loop (score refresh → grade) and catch-up (runCatchupGrading for stranded bets)
- Events are shared (bookie_id=NULL) — never use bookies!inner() joins on events table, get bookie from bets
- Bet.eventId is String not UUID — don't call .uuidString on it
