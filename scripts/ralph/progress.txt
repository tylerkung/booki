## Codebase Patterns
- LiabilityService.calculatePayout(stake:odds:) returns profit only (not including stake)
- American odds formatting: positive gets '+' prefix, negative is as-is
- Theme.font() = Space Grotesk (titles), Theme.bodyFont() = IBM Plex Sans (body text)
- Status colors: Theme.accent (won/open), Theme.danger (lost), Theme.warning (pending), Theme.textMuted (void)
- Event display format: "league · awayTeam @ homeTeam"
- americanToDecimal/decimalToAmerican helpers centralized in PickPresenter
- Bet.eventDescription and Bet.sportLeague provide offline fallbacks when Event is nil
- Always use StatusPill + PickPresenter.mapStatus for pick status display
- UUID case sensitivity: iOS uppercase, PostgreSQL lowercase — always .lowercased() for comparison
- Xcode IDE required for full builds — command-line swiftc can't resolve SwiftData macros
- Complex @ViewBuilder bodies cause type-checker timeouts — extract sub-views proactively
- @Observable migration pattern: remove ObservableObject + @Published, add @Observable macro, change @StateObject → @State, @EnvironmentObject → @Environment(Type.self), .environmentObject() → .environment()
- #unavailable(iOS 26) guard pattern for backward-compatible appearance code
