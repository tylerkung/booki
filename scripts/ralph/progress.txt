## Codebase Patterns
- iOS 18+ / Swift 6.0 / SwiftUI / SwiftData + Supabase (strict concurrency)
- Dark theme: always use Theme.swift — Theme.background, Theme.cardBackground, Theme.accent, Theme.textPrimary, Theme.textSecondary
- Balance convention: internal positive = player owes bookie; negate for player display
- Compliance language: organizer (not bookie), member (not player), pick (not bet), stake (not wager)
- Edge functions in supabase/functions/ — deployed with --no-verify-jwt, auth validated in function code
- @AppStorage incompatible with @Observable — use UserDefaults wrapper functions
- UUID case: iOS uppercase, PostgreSQL lowercase — always .lowercased() for comparison
- BetSlipSheet: activeFieldId routes to single NumericKeypadView, field IDs like "parlay_stake", "{itemKey}"
- Settings/Account view is AccountView.swift (bookie and player sections)
- Dashboard is AnalyticsDashboardView.swift
- Members list is PlayersListView.swift
- Bookie bet detail is in BetsListView.swift
- Player activity/history is PlayerActivityView in AccountView.swift
