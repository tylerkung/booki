## Codebase Patterns
- Landing site is plain HTML/CSS/JS in landing/ directory — no build tools or frameworks
- Dark theme: #0A0A12 background, #00F5D4 accent, Inter (body) + Space Grotesk (headings)
- Nav bar pattern: copy from features.html <nav class="site-nav"> block
- Footer pattern: copy from features.html footer block
- OG tags pattern: see index.html <head> for complete example (og:type, og:url, og:title, og:description, og:image + Twitter card)
- Compliance language: organizer (not bookie), member (not player), pick (not bet), stake (not wager)
- Base URL: https://bookisports.com/
- Existing CSS classes: .container, .section, .btn-primary, .nav-link, .nav-content
- Relative paths from blog/: use ../ prefix for root landing assets (../styles.css, ../assets/)
- Sitemap lives at landing/sitemap.xml
